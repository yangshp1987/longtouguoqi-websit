# docs — 正大明品牌素材库

网站项目内归档的品牌叙事素材，供官网「我们的企业」板块、百年纪念物料、画册与公众号随时调用。

## 文件清单

| 文件 | 内容 | 适用场景 |
|------|------|----------|
| `正大明_过去现在未来_品牌百年叙事.md` | 百年叙事全文：引言 + 过去(1925–2013) + 现在(2014–2025) + 未来(2025–) + 结语；文末附「一句话版」与「官网企业板块 200 字精简版」 | 官网企业板块、画册文案、百年纪念册 |
| `brand-timeline.svg` | 三段式百年时间轴图（过去·朱红浅 / 现在·朱红深 / 未来·鎏金），680×350 | 网页内嵌、公众号配图、PPT |

## 调用建议

- 官网「我们的企业」：用「官网精简版」（约 200 字）+ `brand-timeline.svg` 内嵌；
- 品牌影片/展览物料：用主文「过去/现在/未来」三章做解说词底稿；
- 一句话场景（包装、签名档、简介）：用「一句话版」。

## 事实核对基准

叙事中的年份与事件均对齐官网 `index.html` 发展历程 17 条时间线（1925 商号创立 → 2025 iF 设计奖·百年）。若官网时间线更新，请同步修订本目录文案。
