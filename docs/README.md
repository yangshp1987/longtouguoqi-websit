# docs — 网站项目素材库

网站项目内归档的品牌叙事与运维方案素材，供官网改版、物料制作、域名与备案事务随时调用。

## 文件清单

| 文件 | 内容 | 适用场景 |
|------|------|----------|
| `正大明_过去现在未来_品牌百年叙事.md` | 百年叙事全文：引言 + 过去(1925–2013) + 现在(2014–2025) + 未来(2025–) + 结语；文末附「一句话版」与「官网企业板块 200 字精简版」 | 官网企业板块、画册文案、百年纪念册 |
| `brand-timeline.svg` | 三段式百年时间轴图（过去·朱红浅 / 现在·朱红深 / 未来·鎏金），680×350 | 网页内嵌、公众号配图、PPT |
| `域名更换_备案与迁移方案.md` | 换域名完整方案：现状、备案六步流程与时长、材料清单、EdgeOne 绑定步骤、站内替换清单、收尾与风险 | 域名更换、备案办理、上线切换 |

## 调用建议

- 官网「我们的企业」：用百年叙事的「官网精简版」（约 200 字）+ `brand-timeline.svg` 内嵌；
- 品牌影片/展览物料：用主文「过去/现在/未来」三章做解说词底稿；
- 一句话场景（包装、签名档、简介）：用「一句话版」；
- 换域名：按 `域名更换_备案与迁移方案.md` 的六步执行，代码侧（sitemap 31 处 + 页脚备案号）可交由 AI 助手替换。

## 事实核对基准

- 品牌叙事中的年份与事件均对齐官网 `index.html` 发展历程 17 条时间线（1925 商号创立 → 2025 iF 设计奖·百年）。若官网时间线更新，请同步修订本目录文案。
- 域名方案中的平台规则依据 EdgeOne Pages 官方文档（国内节点添加自定义域名须先完成 ICP 备案、国内版需手动申请 HTTPS 证书）。平台规则如有调整，以控制台提示为准。
